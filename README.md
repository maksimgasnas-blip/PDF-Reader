# PDF Студия — нативный редактор и читатель PDF для Windows

Репозиторий содержит исходный код компактного Win32-приложения на C, примеры PDF,
шрифты и инструкции сборки. Готовый `.exe` намеренно не включён. Приложение использует
движок MuPDF и не требует Electron, браузера, .NET или Java runtime.

При успешной локальной сборке в exe можно включить OCR на русском и английском,
языковые модели и шрифты. Перед распространением бинарника ознакомьтесь с
`THIRD-PARTY.md` и выполните условия лицензий, включая AGPL-3.0 для MuPDF.

## Возможности

- Просмотр PDF, масштабирование, непрерывный и многоколоночный режимы.
- Переход к странице с клавиатуры или вводом номера; поиск текста с подсветкой.
- Выделение и копирование текста, аннотации и заполнение PDF-форм.
- Поворот, дублирование, перемещение и удаление страниц.
- Редактирование текстовых блоков и режим документа с перевёрсткой.
- Форматирование, таблицы, вставка изображений и экспорт в PDF.
- Локальный OCR при сборке MuPDF с Tesseract.
- Win32/GDI интерфейс без браузера и внешнего managed runtime.

Подробные заметки о функциях и ограничениях приведены ниже. Примеры интерфейса:
`screenshot.png` и `screenshot-edit.png`; образцы PDF находятся в `examples/`.

## Сборка из исходников

Нужны Linux или WSL, MinGW-w64 i686 (`gcc`, `g++`, `windres`), `make`, `curl` или
`wget`, Python 3 и достаточно памяти/swap для сборки MuPDF.

```sh
cd native
./fetch-mupdf.sh  # загрузить и собрать MuPDF 1.24.9 с Tesseract OCR
./build.sh        # результат: ../release/PDF-Studio.exe
```

По умолчанию исходники движка загружаются в `native/mupdf-1.24.9-source`.
`WORK=/path/to/cache ./fetch-mupdf.sh` меняет каталог загрузки, `MUPDF=/path/to/src`
можно передать `build.sh` для уже подготовленных исходников. `NOUPX=1 ./build.sh`
отключает необязательное сжатие UPX.

`fetch-mupdf.sh` скачивает MuPDF 1.24.9, применяет совместимый патч для MinGW-w64
и собирает библиотеки с Tesseract. Сценарий сборки проверен только синтаксически
в текущей среде: приложение здесь не пересобиралось, поэтому успешность линковки и
работу GUI на целевой Windows необходимо проверить отдельно. Smoke-тест GUI:
`native/test-gui.sh`; диагностические параметры находятся в `native/src/main.c`.

## Тест навигации

`tests/nav_test.c` проверяет номер страницы, границы и некорректный ввод. При наличии
MinGW gcc:

```sh
gcc -std=c99 -Wall -Wextra -Werror tests/nav_test.c -o nav_test
./nav_test
```

## Структура

- `native/src/main.c` — Win32-приложение, UI-события и навигация.
- `native/src/pdfdoc.c`, `pdftext.c` — PDF-операции на MuPDF.
- `native/src/flow.c` — режим документа, форматирование и экспорт.
- `native/src/textedit.c` — модель редактирования текстовых блоков.
- `native/src/wui.c` — GDI-интерфейс.
- `native/build.sh`, `native/fetch-mupdf.sh` — сборочные сценарии.
- `tests/`, `examples/` — тесты и демонстрационные документы.
